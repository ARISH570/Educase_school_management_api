 School Management API

1. Tech Stack
- Node.js
- Express.js
- MySQL

2. Features
- Add School API
- List Schools by proximity

3. Setup
- Clone repo
- Install dependencies:
   npm install
- Add .env file
- Run:
   node src/server.js
- APIs

5. Add School
POST /api/addSchool

6. List Schools
GET /api/listSchools?latitude=28.7&longitude=77.1
